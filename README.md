#GRADEBOOK MANAGEMENT SYSTEM

##PROJECT DESCRIPTION
This is a program that is student and teacher centered, designed to help teachers easily enter view and search for students in the school.
This program helps avoid  going through students files to enter students information manually while you can just enter the students information,perform calculations and 
view information digitally through the program

#PREREQUISITES
This program works through a programming language called python with a specific version of it
The steps on using the program include
*Download python 3.14 on your computer
*Install an IDE called pycharm that works compatible to the programming language .Its a cross-platform IDE that works on MS Windows ,macOS and linux
*Open the project folder through pycharm
*Run the code so it displays the necessary entries require to access full capabilities of the program

 #HOW IT WORKS
 After  opening the folder through pycharm an option menu is displayed
 OPTION 1:Add a new student
 OPTION 2:Update student's grades
 OPTION 3:Remove a student by name
 OPTION 4:Search for a subject
 OPTION 5:Search a student
 OPTION 6:Show all  students
 OPTION 7:Exit

#IMPLEMENTED FUNCTIONALITIES
Entering number of sttudents in class
Calculating grades e.g class's total and average
hold multiple subjects e.g math,English,Science
Determine highest and lowest grades of subjects in class
Entering a new to an already existing list of students
Update an already existing student's marks
Removing a student from the list using their name
View grades for particular subjects and across the students
